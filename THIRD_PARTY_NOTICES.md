# Third-party code

src/vendor/breakscale is copied from https://github.com/xevrion/breakscale at commit 781b7258d0f0fc8c06199795e554d4ac8031ccde (2026-09-11).
The original MIT license is preserved in that directory. No upstream UI or fonts are copied. Upstream simulation tests are retained. No claims of physical/cloud fidelity are made.

DM Sans and Manrope are self-hosted from Google Fonts under the SIL Open Font License; licenses are preserved in public/fonts/. The upstream canvas annotation layout test is retained as a .reference file because Scale does not copy that canvas UI; engine tests remain executable.
