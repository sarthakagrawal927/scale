# Scale design system

## Direction

A founder's architecture workbench: warm paper, evergreen ink, precise infrastructure diagrams. Operate mode. The living architecture is the signature, not ornamental metrics or component inventory.

## Tokens

Paper #f6f5f1, white #ffffff, ink #252e29, muted #626b64, evergreen #263f35, lime #d8f2aa, amber #925014, red #ad4338. Status has an icon and text as well as color. System sans typography with tabular numbers. Oversized editorial section titles, compact instrument labels, quiet rules. Use 8px spacing rhythm, 12px node corners, restrained offset elevation.

## Interaction

Keep the inspector in document layout so it cannot occlude the canvas. Auto-fit topology until manually zoomed. Drag nodes with pointer capture after gesture promotion. Keyboard-accessible component buttons and zoom controls. Undo/redo sandbox configuration, explicit return to company, preview before paid implementation. Simulation runs in a worker; rendering never owns simulation truth.

## Motion

Traffic motion carries direction. Changes use 160–220ms ease-out; reduced motion disables all animation. Do not animate headline metrics or reshuffle components on every simulation snapshot.

## Responsive

Desktop: sidebar, flexible canvas and fixed inspector. Tablet: compact sidebar, inspector below canvas. Phone: compact header, scrollable metrics, vertically arranged workbench and touch-sized controls. All primary actions remain available.
